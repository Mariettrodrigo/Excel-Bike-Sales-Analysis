# Bike Sales Dashboard

An Excel-based dashboard project analyzing customer purchasing behavior in bike sales using data cleaning, pivot tables, and visualization.

## 📊 Project Overview

This project demonstrates comprehensive data analysis skills using Microsoft Excel, including:
- **Data Cleaning**: Transforming raw data into analysis-ready format
- **Pivot Tables**: Creating multi-dimensional analysis views
- **Data Visualization**: Building interactive charts and dashboards
- **Business Intelligence**: Extracting actionable insights from customer data

## 🎯 Business Objectives

1. Identify key demographic factors influencing bike purchases
2. Analyze income and commute distance impact on buying decisions
3. Compare regional performance and market opportunities
4. Develop customer profiles for targeted marketing
5. Provide actionable insights through interactive visualizations

### Data Files
- `bike_sales_raw_data.csv` - Original dataset with 97 customer records (uncleaned)

## 🚀 Quick Start

### Prerequisites
- Microsoft Excel 2016 or later (Excel 365 recommended)
- Basic understanding of Excel functions, pivot tables, and charts

### Getting Started
1. Clone this repository

## 📈 Key Features

### Data Cleaning
- Standardized categorical variables (Gender, Marital Status)
- Created age brackets for demographic analysis
- Validated data quality and consistency
- Documented all transformations

### Analytical Pivot Tables
1. **Demographics Analysis** - Purchase rates by gender and marital status
2. **Income Analysis** - Financial profiling of customers
3. **Commute Analysis** - Distance impact on purchase decisions
4. **Regional Analysis** - Geographic performance comparison
5. **Age-Education Analysis** - Educational and age factor correlation

### Dashboard Visualizations
- **KPI Cards**: Total sales, conversion rate, average income, customer count
- **Income Chart**: Demographic income comparison
- **Commute Chart**: Distance-based purchase patterns
- **Age Distribution**: Generational buying behavior
- **Regional Performance**: Geographic market analysis
- **Interactive Slicers**: Dynamic filtering by region, age, gender, marital status

## 🔍 Key Insights

Based on the sample data, the analysis reveals:
- **Income Impact**: Higher income correlates with increased bike purchases
- **Commute Distance**: Short to medium distances (0-5 miles) show highest conversion
- **Demographics**: Single professionals aged 30-40 are primary buyers
- **Regional Trends**: Pacific region shows strongest market performance
- **Age Factor**: Young adults (25-40) are most likely to purchase bikes

## 🔄 Data Dictionary

| Field | Type | Description | Values |
|-------|------|-------------|--------|
| ID | Number | Unique customer identifier | Integer |
| Marital Status | Text | Customer's marital status | Married, Single |
| Gender | Text | Customer's gender | Male, Female |
| Income | Number | Annual income (USD) | $30,000-$100,000 |
| Children | Number | Number of children | 0-5 |
| Education | Text | Highest education level | High School to Graduate Degree |
| Occupation | Text | Job category | Manual, Clerical, Professional, Management |
| Home Owner | Text | Home ownership status | Yes, No |
| Cars | Number | Number of cars owned | 0-4 |
| Commute Distance | Text | Distance to work | 0-1 Miles to 10+ Miles |
| Region | Text | Geographic region | Europe, North America, Pacific |
| Age | Number | Customer's age | 28-61 years |
| Age Bracket | Text | Age category | Young Adult, Middle Age, Old |
| Purchased Bike | Text | Purchase status | Yes, No |
