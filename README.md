# Excel-Bike-Sales-Analysis
An Excel based dashboard project analyzing customer purchasing behavior in bike sales using data cleaning, pivot table and visualization

This project analyzes customer purchasing behavior in bike sales using Excel.

📊 Project Overview
The goal of this project is to identify factors influencing bike purchases such as income, age, and commute distance.

⚙ Process
1. Data Cleaning – Replaced short forms (F/M → Female/Male), created age brackets, removed duplicates.
2. Pivot Tables – Created 4 pivot tables to analyze:
   - Average income per purchase
   - Customer commute distance
   - Age brackets
   - Raw age comparison
3. Dashboard – Built an interactive dashboard using charts and slicers (Marital Status, Region, Education).

📈 Tools Used
- Microsoft Excel

🧠 Insights
- Customers with shorter commutes (0–1 miles) are more likely to purchase bikes.
- Middle-aged customers are the most active buyers.
- Higher income groups tend to purchase more.
